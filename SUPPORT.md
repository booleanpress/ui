# Getting help

- **Questions** about using the library — how to compose a component, theme it or set it up — go to
  [Discussions](https://github.com/booleanpress/ui/discussions).
- **Bugs** go to [Issues](https://github.com/booleanpress/ui/issues/new/choose), with a link to a small
  reproduction (a StackBlitz or CodeSandbox project, or a repository), the browser and the package version.
- **A new component or variant** starts as a **New component** issue: every component begins from a spec.
- **Security problems** are reported privately: see [SECURITY.md](SECURITY.md).

The documentation is at <https://ui.booleanpress.com>. Each component page has its examples, its keyboard table and its
API; the Markdown copy of every page ships in the package (`node_modules/@booleanpress/ui/dist/docs/`).
